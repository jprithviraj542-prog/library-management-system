# Library Management System

A console-based Python application to manage library books. Data is saved in a JSON file, so it stays after you close the program.

## Features
- Add a book (with duplicate ID check)
- View all books with Available / Issued status
- Search by title or author
- Issue and return books
- Delete a book
- Data saved in `books.json`

## Technologies
- Python 3
- JSON file handling

## How to Run
```
python library.py
```

## Concepts Used
Lists, dictionaries, functions, loops, file handling (json), input validation.
